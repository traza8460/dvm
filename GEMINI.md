# DVM Project Instructions

- **Auto-Commit & Push**: After finishing changes or tasks in the `dvm` repository, stage all modified project files, commit them, and push directly to `origin main` on GitHub (`https://github.com/traza8460/dvm`).
- **Commit Messages**: Always use short, concise English conventional commit messages (e.g. `feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`).
- **Security & Hygiene**: Never commit `.env`, secrets, credentials, build artifacts (`dist/`), or dependencies (`node_modules/`).
